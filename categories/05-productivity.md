## Resources

### Getting Things Done

- Link: https://gettingthingsdone.com/
- Category: Productivity / Task Management
- Use Case: Build a system for capturing, organizing, reviewing, and executing tasks.
- Strengths: Mature productivity framework, clear workflow logic, and useful for reducing mental clutter.
- Limitations: Can become over-complicated if over-systematized.
- Relevance to Specularis: Useful for building a reliable execution layer across finance, AI, learning, and life systems.
- Notes: Best used as a simple capture-clarify-organize-review-execute framework.
